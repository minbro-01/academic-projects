# 지도 비의존 주행 장면 이해

**Map-free Driving Scene Understanding · 연구 확장 중**

운전 중 교차로에서 차선 보조 기능이 중단되는 경험을 계기로, 차선 표시가 이어지지 않는 상황에서도 카메라로 도로의 연결을 이해할 수 있을지 탐구하기 시작했습니다. 이 관찰은 연구의 출발점이며, 모든 차량에서 기능이 중단되는 원인을 확인했다는 의미는 아닙니다.

## 수행한 작업

- 주행 영상에 영상처리와 기존 인지 모델을 적용했습니다.
- 기존 모델을 결합해 원하는 인식·시각화 결과를 구성했습니다.
- 교차로의 도로 구조 이해와 자차 경로 예측을 연결하는 모델 구성을 구체화했습니다.

초기 작업은 기존 모델을 활용·조합한 경험입니다. 새로 학습한 모델의 성능을 입증한 결과와 구분합니다.

## 후속 연구

현재는 **카메라로 추정한 경로가 주행 계획에 언제 도움이 되는지**를 검증하는 방향으로 연구를 확장하고 있습니다. 경로 추정·주행 후보·유용성 선택을 연결하는 연구용 모듈과 실험 설계를 준비했으며, 실제 카메라 데이터 연결과 GPU 성능 평가는 후속 단계입니다.

연구에서는 추론 입력과 학습 정답을 분리하고, 비교 모델·데이터 분할·실패 사례를 함께 확인합니다. 실제 주행 성능 개선이나 논문 기여가 확정된 연구로 소개하지 않습니다.

## 공개 범위

이 페이지에는 공개 가능한 연구 동기·수행 경험·현재 단계를 정리합니다. 상세 구현과 실험 자료의 공유 범위는 별도로 구분합니다.
