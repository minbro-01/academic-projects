# DRT Policy Recommendation

**RAG·LLM 기반 DRT 정책 지원 · 프로젝트 구현 완료**

DRT(수요응답형 교통) 관련 문서의 벡터 데이터베이스를 구축하고, 문서 검색과 오픈 모델을 이용한 답변 생성을 구현한 프로젝트입니다. 지역 정보와 검색 결과의 제공 조건을 달리한 비교 실험도 수행했습니다.

## 문제와 접근

교통 정책 관련 자료를 활용하려면 문서를 정리하고, 질문과 관련된 내용을 찾고, 이를 답변 과정에 연결해야 합니다. 문서 처리, 벡터 데이터베이스 구축, 지역 정보 연결, 검색, 언어 모델을 이용한 답변 생성으로 이어지는 작업을 수행했습니다.

## 수행한 작업

- 논문·보고서 PDF를 처리하고, 문서 분할과 임베딩을 거쳐 벡터 데이터베이스를 구축했습니다.
- 질의와 관련된 자료를 검색하는 코드를 구현했습니다.
- 지역 정보를 연결하고, 오픈 모델을 불러와 DRT 운행 전략에 관한 답변을 생성했습니다.
- 추가 정보 없음, 지역 정보 제공, 지역 정보와 검색 결과 제공 조건의 답변을 비교하고 실행 출력과 평가 기록을 남겼습니다.

## 완료 범위

**문서 처리·벡터 DB 구축·검색·오픈 모델 답변 생성 구현과 조건별 실험을 완료했습니다.**

저장소의 노트북 버전, 폴더 구성, 실행 안내를 정리하는 작업은 완료된 프로젝트의 결과물을 더 쉽게 살펴보고 재사용하기 위한 작업입니다.
